# PPE-Detection-System

## Overview
A computer vision project designed to automatically detect personal protective equipment (PPE) in industrial images using YOLO and Python.

## Objectives
Detect safety helmets.
Identify PPE upper-body protective clothing.
Generate bounding-box predictions on images.
Support automated industrial safety monitoring.

## Technologies
Python
Ultralytics YOLO
OpenCV
Roboflow
NumPy

## Workflow
1. Prepare and organize the image dataset.
2. Use annotated data to train the model, if applicable.
3. Run inference on input images.
4. Visualize detected objects using bounding boxes.
5. Review prediction quality and evaluate model performance.
